守护策略

基于被动观测的隔离阈值与窗口策略

账号自动禁用

账号任一次被动观测降智（缺 thinking）立即禁用，不再参与选号（可在账号降智统计面板手动恢复）。

关闭后仅保留手动禁用与账号降智统计；已自动禁用的账号需手动恢复。

出口持续降智自动停用

同一出口累计隔离达到阈值后永久停用（写入状态文件，重启不恢复），停止调度与被动观测，避免持续降智空烧流量。面板「启用 / 恢复」可重新放行。

关闭后仅临时隔离，到期仍会复测；已自动停用的出口需手动启用。

同一出口累计隔离达到该次数（含）后自动停用；默认 3

节点账号窗口

节点在窗口时长内累计使用的账号数达到上限后，自动停用该节点冷却（不参与调度与探测），冷却结束后自动恢复，用于规避同一出口 IP 短时间内使用多个账号的批量标记。

窗口内累计账号数达到该值即冷却；0 表示关闭该功能；默认 3

冷却时长与滚动窗口跨度（分钟）；默认 1440（24 小时）
